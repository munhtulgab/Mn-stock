# MSE Хөрөнгийн Зөвлөх

Монголын хөрөнгийн биржид (MSE) бүртгэлтэй компаниудын ханшийн түүх болон
санхүүгийн тайланд үндэслэн авах/зарах/хүлээх (BUY/SELL/HOLD) санал өгдөг
систем. Next.js (App Router) + MongoDB дээр суурилсан бөгөөд Vercel дээр
deploy хийхэд зориулагдсан.

## Өгөгдлийн эх сурвалж

Албан ёсны, баримтжуулсан API байхгүй тул систем нь MSE-ийн өөрийн нээлттэй
өгөгдлийн порталаас (`https://open.mse.mn`) шууд уншиж (scrape) авдаг:

- `/securities` — бүртгэлтэй компаниудын жагсаалт (симбол, нэр, ангилал)
- `/securities/{id}/tab/tradeinfo` — тухайн компанийн 1999 оноос хойших
  өдөр тутмын нээлт/хаалт/дээд/доод үнэ, эзлэхүүн зэрэг арилжааны түүх
- `/securities/{id}/tab/financials` — сүүлийн улирлын санхүүгийн тайлан
  (P/E, EPS, ROE, ROA, цэвэр ашиг гэх мэт)
- `/securities/{id}` — компанийн мэдээ мэдээллийн жагсаалт (AI шинжилгээнд
  ашиглагдана)

Энэ бол албан ёсоор баримтжуулаагүй, гэхдээ MSE өөрөө олон нийтэд зориулж
нээлттэй тавьсан хуудас тул сайт өөрчлөгдвөл `lib/mse/*.ts` доторх
parser-үүдийг шинэчлэх шаардлагатай болно.

## Архитектур

- **`lib/mse/`** — `open.mse.mn`-с HTML/JSON татаж parse хийх функцүүд
- **`lib/sync.ts`** — цаг хугацаагаар хязгаарласан (time-boxed) sync batch,
  cursor ашиглан компани бүрийг дараалан шинэчилнэ
- **`lib/recommendation.ts`** — техник (SMA20/50, RSI14, momentum, 52 долоо
  хоногийн байрлал) болон фундаментал (P/E зах зээлийн дундажтай харьцуулах,
  ROE, EPS) шинжилгээг нэгтгэсэн дүрэмд суурилсан оноон систем — энэ нь
  үндсэн, үнэ төлбөргүй, бүх компанид шууд ажилладаг дохио
- **`lib/ai/`** — сонголтоор ажилладаг, олон LLM ашигладаг "AI дүн шинжилгээ"
  (нэг компанийн гүнзгий шинжилгээ, зорилтот үнэ/stop-loss/эрсдэл бүхий).
  Claude (Anthropic), Google Gemini, Groq, OpenRouter — эдгээрээс тохируулсан
  бүх түлхүүрийг зэрэг дуудаж, дийлэнх олонхийн (majority vote) саналыг
  нэгтгэн "consensus" дүгнэлт гаргана; хариу дээр үйлчилгээ тус бүрийн
  дохио/итгэлцлийг тусад нь харуулна. Нэг ч түлхүүр тохируулаагүй бол энэ
  хэсэг зүгээр л идэвхгүй харагдана — систем бусад бүх хэсгээрээ бүрэн
  ажиллана.
- **`app/settings/`** — API түлхүүрүүд (4 LLM провайдер) болон мэдээний эх
  сурвалжийн линкүүдийг удирддаг тохиргооны хуудас. Тусдаа нууц үг шаардахгүй
  — апп руу нэвтэрсэн хэрэглэгч л хандана (`(app)` layout аль хэдийн нэвтрээгүй
  бол `/login` руу шилжүүлдэг).
- **`lib/mse/newsSources.ts`** — Тохиргоо хуудсан дээр нэмсэн мэдээний
  сайтуудаас (ямар ч сайт байж болно, зөвхөн MSE биш) текст болон гарчгуудыг
  татаж, AI шинжилгээний нэмэлт контекст, мөн компанийн дэлгэрэнгүй хуудасны
  холбоотой мэдээ болгон ашиглана. Эх сурвалж бүр статустай буцдаг тул
  ажиллахгүй байгаа линкийг Тохиргоо доторх "Эх сурвалжуудыг шалгах" товчоор
  шууд харна.
  - **Facebook** (`lib/mse/facebook.ts`): нэвтрээгүй хүнд агуулгаа
    харуулдаггүй — www, m, touch, mbasic, page plugin бүгд login руу
    шилжүүлэх эсвэл JavaScript-ээр дүүргэдэг хоосон бүрхүүл буцаадаг.
    Үнэгүй нийтийн bridge-үүд ч энэ хананд унадаг: RSSHub нь Cloudflare
    шалгалт буцаасан, RSS-Bridge-ийн 4 инстанс бүгд Facebook дээрээ
    ("Unable to find anything useful", "Unable to get the page id")
    таслагдсан. Гурван зам үлдэнэ — тохируулахад хялбараас нь эхэлж
    дарааллаар оролдоно:

    1. **Apify түлхүүр** (Тохиргоо → "Apify түлхүүр"). apify.com дээр
       үнэгүй бүртгүүлж (карт шаардахгүй, сар бүр үнэгүй кредиттэй)
       токеноо хуулахад л хангалттай — `apify/facebook-posts-scraper`
       actor нь хуудасны постуудыг JSON болгож өгдөг. Өөрийн Facebook
       бүртгэлийг огт хөндөхгүй тул хамгийн аюулгүй нь.
    2. **Session cookie** (Тохиргоо → "Facebook cookie"). Бүртгэлийн харж
       чадах бүх хуудсыг уншина. `mbasic.facebook.com`-оос уншина —
       JavaScript-гүй хувилбар нь постуудыг серверээс бэлэн HTML болгон
       өгдөг. Cookie зөвхөн facebook.com руу явна; `c_user`, `xs`,
       `datr`, `sb`, `fr`-ээс бусдыг хадгалахгүй хаяна. Уг cookie нь
       бүртгэлд бүрэн эрх өгдгийг санаж, туслах бүртгэл ашиглах нь зөв.
    3. **Page access token** — зөвхөн өөрийн эзэмшдэг хуудсанд.

    Гурвуулаа байхгүй бол facebook.com эх сурвалж `login_required`
    статустай алгасагдана. Постын огноог Apify-н `time` талбараас, cookie
    замд `<abbr data-store>`-ийн epoch эсвэл бичвэр хэлбэрээс (жишээ нь
    "5 August at 10:03") уншиж, бусад мэдээтэй хамт огнооны дарааллаар
    эрэмбэлнэ.

    Apify-н үр дүнг `facebookSnapshots` цуглуулгад 30 минут хадгална:
    компани бүрийн мэдээ бүтээх бүрд эх сурвалжуудыг дахин уншдаг тул
    кэшгүй бол нэг хуудас үзэхэд арваад ижил scrape ажиллаж, үнэгүй
    кредитийг дэмий үрнэ. Хугацаа хэтэрсэн ажиллагаа Apify талд дуусдаг
    учир дараагийн оролдлого нь сүүлийн амжилттай run-ы үр дүнг
    (`runs/last/dataset/items`) шинээр кредит зарцуулалгүй авчирна.
  - **RSS/Atom-ыг эрхэмлэнэ** (`lib/mse/feed.ts`): эх сурвалж бүрийн хувьд
    эхлээд `<link rel="alternate">` заалтыг, дараа нь `/rss`, `/rss.xml`,
    `/feed` замуудыг шалгана. Feed олдвол хуудсыг зулгаахын оронд түүнийг
    ашиглана — цэс, хөл хэсгийн шуугиангүй, огноо болон хураангуйтай цэвэр
    өгөгдөл гарна. Feed-ийн хаягийг шууд эх сурвалж болгон нэмж бас болно.

  - **Апп нь ямар ч эх сурвалж дагалдуулж ирдэггүй** — `newsSources`-ийн
    анхны утга хоосон. Жагсаалтыг бүхэлд нь Тохиргоо хуудсаас хэрэглэгч
    удирдана; энд ямар ч сайт нэмж, хасаж болно.

  - Эх сурвалж бүрийн буцаах статусууд:

    | Статус | Утга |
    | --- | --- |
    | `ok` | Агуулга амжилттай татагдсан (RSS эсвэл HTML-ээс) |
    | `tls_error` | Сайтын SSL гинж дутуу — доорх засварыг үз |
    | `timeout` | 15 секундэд хариу ирээгүй |
    | `http_error` | Сайт алдааны код буцаасан (403/429 бол бот хамгаалалт байж болзошгүй) |
    | `empty` | Хуудсаас текст олдоогүй — агуулгаа зөвхөн JavaScript-ээр ачаалдаг |
    | `login_required` | Нэвтрэлт шаарддаг (Facebook гэх мэт) |

    Аль ч линкийн одоогийн байдлыг Тохиргоо → **"Эх сурвалжуудыг шалгах"**
    товчоор шалгана. Ажиллаж байгаа эх сурвалж дээр татсан тэмдэгтийн тоо,
    гарчгийн тоо, RSS ашигласан эсэх харагдана.

  - `mse.mn`-ийг эх сурвалж болгон нэмэх шаардлагагүй: тэр сайт агуулгаа
    зөвхөн JavaScript-ээр ачаалдаг бөгөөд МХБ-ийн мэдээг апп аль хэдийн
    `open.mse.mn`-ээс компани тус бүрээр нь шууд татдаг.

  - **SSL сертификатын гинж дутуу** (`tls_error`): зарим сайт (жишээ нь
    `marketinfo.mn`) leaf сертификатаа л илгээж, intermediate-ээ илгээдэггүй.
    Хөтөч дутуу гэрчилгээг өөрөө нөхөж татдаг тул хэвийн харагддаг ч Node,
    curl, Vercel зэрэг сервер талын клиент "unable to get local issuer
    certificate" гэж унана.

    **Үүнийг апп автоматаар засна.** `lib/tls/extraCa.ts` дахь `recoverChain`
    нь хөтчийн адил ажиллана: сертификат дотор өөрийнх нь гаргагчийг хаанаас
    татахыг заасан (AIA "CA Issuers") тул дутуу холбоосыг татаж аваад
    итгэмжлэлд нэмнэ. Хэрэглэгч юу ч хийх шаардлагагүй.

    Аюулгүй байдал сулраагүй: сертификатыг унших ганц арга нь шалгалтгүй
    холболт учир *танилцах* холболт шалгалтгүй явдаг, гэхдээ түүнээс авсан
    цорын ганц зүйл нь "нэр дэвшигч гэрчилгээг хаанаас татах вэ" гэсэн
    хаяг юм. Өгөгдөл зөөх жинхэнэ хүсэлт `rejectUnauthorized` асаалттай
    явагддаг тул гинж нь жинхэнэ нийтийн root хүртэл хүрч, хостын нэр
    таарах ёстой хэвээр. Туршилтаар баталсан: сэргээсэн гэрчилгээтэй
    үед амжилттай, түүнгүйгээр яг адилхан татгалздаг.

    **Гар аргаар** (AIA заалтгүй ховор тохиолдолд) Тохиргоо → "Нэмэлт SSL
    сертификат" талбарт дутуу гэрчилгээг PEM хэлбэрээр нэмж болно:

    ```
    openssl s_client -showcerts -connect marketinfo.mn:443 </dev/null
    ```

- **`app/page.tsx`**, **`app/stock/[symbol]/page.tsx`** — dashboard болон
  компани тус бүрийн дэлгэрэнгүй хуудас
- **`app/api/sync`** — MongoDB руу шинэ дата татах endpoint (Vercel Cron
  болон гараар дуудахад зориулагдсан)

### AI дүн шинжилгээг тохируулах

`/settings` хуудсан дээр (эсвэл дараах орчны хувьсагчаар нөөц болгон):

| Провайдер | Тохиргооны талбар | Env var нөөц | Анхны модель |
|---|---|---|---|
| Anthropic (Claude) | Anthropic (Claude) | `ANTHROPIC_API_KEY` | `claude-sonnet-5` |
| Google Gemini | Google Gemini | `GEMINI_API_KEY` | `gemini-2.5-flash` |
| Groq | Groq | `GROQ_API_KEY` | `llama-3.3-70b-versatile` |
| OpenRouter | OpenRouter | `OPENROUTER_API_KEY` | `openai/gpt-4o-mini` |

Дор хаяж нэгийг тохируулахад л AI дүн шинжилгээ идэвхжинэ; хэд хэдийг
тохируулсан тусам consensus (олонхийн санал) илүү найдвартай болно.
Тохиргоо хуудсан дээрх утга MongoDB-д хадгалагдах бөгөөд env var-аас
илүү жин авна (env var зөвхөн нөөц/fallback).

## PWA — "Апп" болгон суулгах

Систем Progressive Web App болгон бүтээгдсэн тул утас эсвэл компьютер дээр
жинхэнэ апп мэт нүүр дэлгэц (home screen) дээр суулгах боломжтой:

- **Android / Chrome**: header-ийн баруун талд гарч ирэх **Install App**
  товч дээр дарна, эсвэл browser цэснээс "Install app" сонгоно.
- **iOS / Safari**: Share → "Add to Home Screen" сонгоно.

Суулгасны дараа апп бие даасан цонхонд (address bar-гүй) нээгдэнэ. Лого,
нэр (`app/manifest.ts`), icon бүгд `public/icons/` доторх зургуудаас
үүсдэг.

## Push мэдэгдэл ("Апп шиг" notification)

Header-т байрлах 🔔 товчийг дарж мэдэгдэл идэвхжүүлбэл, компанийн ханшны
дохио (BUY/SELL/HOLD) өөрчлөгдөх бүрт (жишээ нь `APU HOLD→BUY`) push
мэдэгдэл ирнэ. Энэ нь `/api/sync` (Vercel Cron) ажиллах бүрд өмнөх
дохиотой харьцуулж, ялгаа гарвал бүх идэвхтэй subscriber-т нэг нэгтгэсэн
мэдэгдэл илгээнэ (`lib/signalHistory.ts`, `lib/push.ts`).

Ажиллуулахын тулд VAPID түлхүүр үүсгэх шаардлагатай:

```bash
npx web-push generate-vapid-keys
```

Гарсан `publicKey`/`privateKey`-г `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`,
`NEXT_PUBLIC_VAPID_PUBLIC_KEY` (públic key-тэй ижил утга) орчны
хувьсагчдад тохируулна (`.env.example`-г үзнэ үү). Эдгээргүй бол 🔔 товч
харагдахгүй/идэвхгүй байх бөгөөд систем бусад бүх хэсгээрээ хэвийн
ажиллана.

> Санамж: push мэдэгдэл зөвхөн жинхэнэ (incognito биш) browser дээр
> ажиллана — Chrome incognito горимд Push API-г санаатайгаар идэвхгүй
> болгосон байдаг.

## Локал ажиллуулах

```bash
npm install
cp .env.example .env.local   # MONGODB_URI-г бөглөнө
npm run dev
```

Эхний удаад өгөгдлийн сан хоосон байх тул нэг удаа sync хийх шаардлагатай:

```bash
curl http://localhost:3000/api/sync?maxMs=250000
```

Энэ нь компаниудын жагсаалтыг бүрэн, ханш/санхүүгийн мэдээллийг цаг
хугацааны хязгаарын дотор аль болох олон компанид татна. 162 идэвхтэй
компанийг бүрэн эхний удаад дуусгахын тулд дээрх командыг хэд хэдэн удаа
дахин дуудах шаардлагатай байж болно (cursor-ыг санадаг тул үргэлжлээд л
явна).

## Vercel дээр deploy хийх

1. GitHub дээрх энэ repo-г Vercel дээр "Import Git Repository" хийнэ.
2. Дараах орчны хувьсагчдыг Vercel Project Settings → Environment
   Variables дотор тохируулна:
   - `MONGODB_URI` — MongoDB Atlas холболтын мөр (заавал)
   - `CRON_SECRET` — `/api/sync`-г хамгаалах санамсаргүй нууц үг (санал
     болгож байна; Vercel Cron үүнийг автоматаар `Authorization: Bearer`
     header-т нэмнэ)
   - AI провайдеруудын түлхүүрийг env var-аар биш, deploy хийсний дараа
     шууд `/settings` хуудаснаас нэмэхийг зөвлөж байна (дээрх хүснэгтийг
     үзнэ үү) — редеплой хийх шаардлагагүй.
   - `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `NEXT_PUBLIC_VAPID_PUBLIC_KEY`,
     `VAPID_SUBJECT` — push мэдэгдэл идэвхжүүлэхэд (сонголт, дээрх Push
     мэдэгдэл хэсгийг үзнэ үү)
3. Deploy хийсний дараа эхний удаад `/api/sync`-г MONGODB_URI-тэй адил
   `CRON_SECRET`-ийг `Authorization: Bearer <CRON_SECRET>` header-т дамжуулан
   гараар хэд хэдэн удаа дуудаж, бүх компанийн түүхийг эхлүүлнэ (доорх
   жишээг үзнэ үү).
4. `vercel.json`-д тохируулсан Cron ажил өдөр бүр (UTC 10:00 = Улаанбаатарын
   цагаар 18:00) шинэ ханшийг автоматаар татна.

```bash
curl -X POST "https://<your-app>.vercel.app/api/sync?maxMs=250000" \
  -H "Authorization: Bearer $CRON_SECRET"
```

## Хязгаарлалт

- Энэ систем нь хөрөнгө оруулалтын албан ёсны зөвлөгөө биш, зөвхөн
  мэдээллийн зорилготой.
- Одоогоор зөвхөн "Хувьцаа" (stocks) ангиллыг дэмждэг; бонд, сан гэх мэтийг
  дараа нэмж болно.
- Фундаментал шинжилгээ зөвхөн сүүлийн нэг улирлын тайланд үндэслэдэг тул
  түүхэн чиг хандлага (жишээ нь EPS-ийн өсөлтийн хурд) орсонгүй.
